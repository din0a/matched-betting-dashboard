Supported bookmaker directory

Bet Right, bet365, BetDeluxe, BetNation, Chalk24, Dabble, GoldBet, Ladbrokes, mybet, Neds, OKEBET, Palmerbet, Picklebet, PointsBet, Punt123, RealBookie, RobWaterhouse, Sportsbet, TAB, TABtouch, topbet, UltraBet, Unibet. Excluded as requested: MintBet, BearBet and ReadyBet. Fantasy-sports apps and the generic Sports folder are also excluded. A listed bookmaker is a filter option, not proof of a connected live feed.

Feed connection status

Not connected to live Betfair or bookmaker APIs. You can import matched rows or use an authorised HTTPS feed. A local HTML file cannot safely hold Betfair login credentials or bypass bookmaker restrictions. For real cross-bookmaker scanning, a server-side adapter must identify identical events, markets, outcomes, start times and settlement rules.

Automatic odds scanner

Load an odds CSV or configure an HTTPS JSON feed. The scanner recalculates and filters matches automatically; it can poll a feed while this page is open.

JSON feed: array of objects or {"markets":[...]}; same column names as CSV. One row represents one comparable back/lay selection, not necessarily an entire event. For bookmaker-versus-bookmaker two-outcome hedges, set exchange to the opposite bookmaker, lay to opposite odds, and hedge_mode to opposite. This requires a verified two-outcome market. Browser CORS restrictions and provider API terms apply. A feed must already provide matched back/lay selections: this page does not scrape bookmaker sites or independently match market identifiers. Feed URL is not stored or sent anywhere other than the URL you enter.
